# Fotos da loja (apresentação de fundo)

Coloque aqui as fotos novas (interior, balcão, PCs, vitrine):

- `extras/01.jpg`, `02.jpg`, … (qualquer nome `.jpg`/`.png`/`.webp`)
- Ou liste em `manifest.json` (opcional)

O fundo do site lê:
1. `approach/` — sequência “carro do Google” se aproximando
2. fotos da raiz (`maps-*.jpg`) e `extras/`

Depois de adicionar, avise o agente ou rode o preview em
`design-system/fundo-loja.html`.
