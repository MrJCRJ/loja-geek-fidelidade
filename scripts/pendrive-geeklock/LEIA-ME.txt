GeekLock 1.1.9 — instalação pelo pendrive
========================================

Pré-requisito
- GeekCentral online (VPS): https://api.geekloja.com.br
- Painel dono: https://admin.geekloja.com.br
- Pendrive label GEEKLOCK (~15 G) — não misturar com outro USB

Instalar em cada PC de jogo
1) Abra a pasta do pendrive (raiz ou pasta GeekLock).
2) Clique duas vezes em INSTALAR-GEEKLOCK.bat
3) Aceite o UAC (administrador).
4) Espere copiar para C:\GeekLock e abrir o CADASTRO.
5) Digite o nome da estação e Conectar à Central.

O que o .bat faz
- Copia o pack para TEMP antes do UAC (letra do USB não some)
- Apaga C:\GeekLock e dados antigos do app (pareamento incluso)
- Copia o pack novo (1.1.9) — sem PIN local; destrave/sair só pelo Central
- Grava config com serverUrl=https://api.geekloja.com.br
- Registra tarefa GeekLockHarden (bloqueia pendrive só com tela travada; webcam livre)
- Coloca autostart no login do Windows
- Abre o GeekLock no assistente de cadastro

Se der erro
- "GeekLock.exe nao encontrado": use o .bat que está na pasta GeekLock do pendrive
- UAC não abre: botão direito no .bat → Executar como administrador
- Não conecta: confira https://api.geekloja.com.br/api/health no celular

Atualização depois
- Com a máquina já instalada, o GeekLock baixa update do GitHub sozinho
- Para forçar instalação limpa de novo, rode este .bat outra vez
